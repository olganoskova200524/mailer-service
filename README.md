# Mailer Service

Учебный проект сервиса email-рассылок на Django.

Проект реализует:
- управление клиентами (получателями рассылок);
- управление сообщениями;
- управление рассылками;
- отправку по требованию (из интерфейса и через management-команду);
- учёт попыток рассылок;
- роли **пользователь** и **менеджер**;
- статистику и отчёты по рассылкам;
- серверное и клиентское кеширование основных страниц.


## Технологии

- Python 3.12
- Django 5.2
- Poetry
- Bootstrap 5 (через CDN)
- flake8 (dev-зависимость)


## Роли пользователей

### Пользователь

- управляет только своими рассылками, сообщениями и получателями
- видит только свои данные
- может запускать свои рассылки вручную


### Менеджер

- видит всех пользователей, все рассылки, сообщения и клиентов
- может блокировать/разблокировать пользователей
- не может:
    - редактировать чужие данные
    - удалять чужие данные
    - запускать чужие рассылки

## Страница /statistics/

Страница предназначена для отображения статистики рассылок.

### Для обычного пользователя

- Количество рассылок
- Количество сообщений
- Количество клиентов
- Количество попыток отправки
- Успешные / неуспешные попытки
- Подробная статистика по каждой своей рассылке

### Для менеджера

- Общая статистика по системе
- Статистика всех рассылок
- Сводка по каждому пользователю
- Общие показатели успешности

## Отправка рассылок

Ручная отправка доступна **только владельцу рассылки**.

Каждая попытка отправки фиксируется в модели `MailingAttempt` и содержит:
- Статус отправки (успешно / неуспешно)
- Время попытки
- Ответ сервера
